# Core integration under Issue #81

The integration preserves the reviewed `@martlet/core` package identity, source version, CSS, fonts, exports and historic theme tags. It combines the existing live-main release-authority guard, GitFlow branch policy and generated TypeScript design/foundation provenance fixes without restoring old theme package metadata. The genuine Core version is already published and must never be republished. The declaration additions are forward source improvements; registry verification refers to the independently verified reviewed published archive, not a claim that the new source was published.

Publication remains disabled in tag-release proposals. Existing manual stage support is preserved; no workflow dispatch, tag, release or npm mutation is part of this integration. Release ancestry follows feature → develop → release branch → main, followed by a main back-merge. Current branch and approval controls must remain intact.

Read-only verification jobs have ten-minute bounds and obsolete-run cancellation. Feature pushes no longer duplicate pull-request verification. All assertions and signature/provenance checks remain.
